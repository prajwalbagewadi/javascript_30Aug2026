# 🎯 Recommended order

If your goal is **getting into software development**, don't try to finish every advanced topic.

Follow:

```text
JavaScript Fundamentals
        ↓
Functions
        ↓
Arrays + Objects
        ↓
Modern JavaScript
        ↓
Async JavaScript
        ↓
DOM + Browser
        ↓
HTTP + Fetch
        ↓
Node.js
        ↓
Express
        ↓
REST APIs
        ↓
Database
        ↓
Authentication
        ↓
Testing
        ↓
Projects
```

### ⭐ Highest-priority topics

If you want the **80/20 JavaScript**, prioritize:

**Variables → Functions → Arrays → Objects → Destructuring → Higher-order functions → Promises → Async/Await → Event Loop → DOM → Fetch → Modules → Node.js → Express → REST APIs → Database.**

That gives you a very solid foundation for moving into **React + Node.js** afterward.
